# AVI

Venue site for the “algorithms sell ads, AVI fills tables” brand.

- Live: https://whimsyandweeds.github.io/avi-marketing/
- Partner intake: https://whimsyandweeds.github.io/avi-marketing/partners.html

90% dark neutrals, 10% violet. Logo and palette match the deck handoff.

## Palette

- Rich black `#0A0A0B` page
- Charcoal `#1A1A1D` cards
- Graphite `#2A2A2E` surfaces
- Border gray `#3A3A3F`
- Stone gray `#9A9AA9` secondary text
- Off-white `#F5F2EB` headlines
- Electric violet `#7A2CFF` CTA
- Deep violet `#5B1ED1` hover
- Soft lavender `#B78AFF` icons
- Neon glow `#C084FC`

## Leads

Forms save to `localStorage` until a backend exists. Paste Formspree endpoints into `app.js`:

```js
const FORMSPREE_VENDOR = "https://formspree.io/f/xxxxxxxx";
const FORMSPREE_WAITLIST = "https://formspree.io/f/yyyyyyyy";
```
